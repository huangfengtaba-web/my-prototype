## 2. 各分区页签与流转

### 2.1 index.html（总览）
顶部 4 KPI（机台 8 / Lot 待排 120 / Reticle 156 / 超水位 3）→ 功能架构 SVG（数据层→前处理→算法层→后处理→结果层→SDR/QTMS 联动）→ 8 张模块入口卡（点卡片进入对应分区）→ 13 条 RFP 覆盖矩阵（✅/🟡）→ 交付物索引（指向 03_文档 的链接当前标注"待产出"的字段，随本批文档交付后生效）。

### 2.2 config_zone.html（Production Config）
| 页签 | 流转出口 |
|---|---|

| Priority Config | 优先级映射表（Priority→Classify，含 Normal/Super Bullet） |

### 2.3 model_zone.html（Model Control）
Eqp Group（新增/编辑/删除，占用禁改删）→ Data Parameter（Scheduling 显示 Set/Type/Scope）→ **Schedule Model** →「配置」→ **Model Configuration 子页**（Basic Info / Model Selection：Diffusion/Etch/Litho/Reticle Inspection/Wet / Data Selection：Eqp Group + Variable Config / Config）→「Run」单次执行（Running 时禁用：This Model is running）→ 运行结果落 **log_zone**。

### 2.4 result_litho.html（Scheduling Result）
Barc Schedule（12 列，Is Release/Reason 看 ⑤ 反推结论）→ Scanner Schedule-Chart（三态条 + Reticle 条 + Recipe Mode 五色开关 + QTMS 红框 + Eqp 详情弹窗）→ Scanner Schedule-List（12 列，CSV 下载）→ Litho OverLap（⚠ C 级缺口占位）→ Lot 加工流（选 Lot 看 step 带 + QTime 弧线）→ Wafer 加工时间（⚠ C 级缺口占位 + WPH 示意）→ **中间结果**（选运行批次 RUN-* → 六步切换：预处理/Reticle预组批/Lot细排程 chunk/后处理/BARC 反推/光罩状态推演，各步过程产物表 + CSV 导出，对应计划序号37 工程化-中间结果输出）。

### 2.5 result_reticle.html（Scheduling Result）
Reticle Schedule-Chart（五态色块甘特，hover 11 字段）→ Reticle Schedule-List（11 列 + CSV）→ **Reticle Transport**（搬送记录 9+1 列 + SVG 当日路径 + 「下发 SDR」两方案说明）。

### 2.6 log_zone.html（System Log）
Scheduling Log（筛选：Model Name 多选 / Model Type / End Time 90 天 / Status 多选）→ Error/Abnormal 行「View Error」**带查询条件跳转 Error Management** → Error Management（Create Time 逆序 + Detail 弹窗）。

### 2.7 复用页
- stacking_bond_ui_v6.html：EQP Loading + Lot Stacking Bond 产能分配（Stacking 四态色），tooltip/评论模式为全站代码基准。
- equip_temp_layer_config.html：温层配置详细版（Recipe-Eqp-Temperature / Capability-Temperature Change Cost Time），由 config_zone Temperature Config 简版进入。

## 3. 主用户路径（场景串联）
1. **配置→运行→看结果**：config_zone（Lot Control/Fix Lot/Reticle Config）→ model_zone.Schedule Model「Run」→ log_zone.Scheduling Log（Success）→ result_litho/result_reticle 查看甘特 → result_reticle.Transport 下发 SDR。
2. **急货故事线**：config_zone.Fix Lot（LOT-A01 急单）→ result_litho.Scanner Chart（LOT-A01 10:00 上 IMM01，Jobprepare 星标）→ result_reticle.Chart（RT-0101 五态：09:10 IRIS→09:30 搬送→09:45 就绪→10:00 Process）→ Transport（IRIS/Load/Unload 三条指令，Super 优先级）。
3. **异常追溯**：result 页异常表现 → log_zone.Scheduling Log（Error 行）→ View Error → Error Management（Detail 弹窗看 DATA_ERROR/MODEL_ERROR 详情）。

### A2. log_zone.html · Run Trace（溯源"事前"）
- 入口：Scheduling Log 每行新增 RUN_ID 列与 Trace 按钮（或页签直选 Run）。
- 版本链四卡：RUN → SNAP_ID（输入快照，含对账批次引用与上轮 diff）→ CFG_VER（配置版本，diff 高亮）→ ALGO_VER（算法版本）→ 结果版本。
- 决策审计表：Lot→机台 reason_code（KEY_LOT_PRIORITY / SAME_RETICLE_TRAIN / QT_WATERLEVEL_OK / SAME_RECIPE_BATCH / LOAD_BALANCE / R2R_FEEDBACK / QT_RISK_AVOID / DATA_QUARANTINE）+ 评分因子 + 约束命中 + Replay 重放结论。
- 出口：中间结果页（六步逐行溯源）、数据对账批次、重放对比。

### A3. result_litho.html?page=plan · 计划 vs 实际（准确性"事后"闭环）
- MES 实绩回流（TrackIn/TrackOut）与计划逐条比对：双条甘特（蓝框=计划/实心=实际，绿/橙/红/灰四态）+ 偏差表（开始/结束偏差分钟数 + 原因）。
- KPI：实绩回流批次、时间达成率、平均开始偏差、QTime Violation、未完成。
- 闭环动作：偏差超 ±15min 自动生成校准建议（WPH/搬送耗时/温层代价），下轮排程生效。

### A4. 版本徽章条（result_litho / result_reticle 全二级页面）
- 排程版本 RESULT-V20261024-1755 · RUN_ID · 输入快照 SNAP-20261024-1750（数据水位 17:50 · 对账 RC-1755）· CFG/ALGO 版本 · Run Trace / 中间结果溯源直达链接。
