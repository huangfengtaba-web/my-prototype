## 1. 总述

### 1.1 表分类与数量
| 类别 | 前缀 | 数量 | 表 |

**合计 28 张** = 设计书明示结构表 17 张 + 正文引用隐含表 5 张（⚠本方案补齐）+ 模型管理/日志缺口表 3+2 张（缺口 A1/A2，⚠本方案补齐）+ Reticle 搬送指令 1 张（缺口 B 级 SDR 联动，⚠本方案补齐）+ 算法中间过程/溯源表 3 张（需求37，⚠本方案补齐）。

### 1.2 命名与通用约定
- 大写下划线；源表 `SOURCE_`、自有域 `FSO_`；温层两表沿用设计书原文小写。
- 通用审计字段：`ID` NUMBER 主键（序列/自增）、`CREATED_BY/CREATED_TIME`（部分表为 CREATE_BY/CREATE_TIME，照设计书原文）、`UPDATED_BY/UPDATED_TIME`、`IS_DELETE`（1 删 0 未删）、`DATA_VERSION` 乐观锁（仅设计书给出的表带）。
- 时间 DATE 秒级；"相对秒"字段照设计书 §3.3.2.3.2 标注。

### 1.3 核心数据流（ER 简述）
```
SOURCE_LOT ─┬─ SOURCE_PRODUCT_FLOW(STEP_SEQ/LAYER/RETICLE_ID/CAPABILITY) ─→ 预处理 ─→ FSO_SCHEDULE_RESULT
SOURCE_LOT_REMAIN_QTIME ─→ BARC 放货计算 ─→ BARC_RELEASE_BATCH
SOURCE_EQP_INFO + SOURCE_EQP_STATUS + SOURCE_EQP_CHAMBER_STATUS + SOURCE_EQP_RECIPE ─→ 机台可用性
SOURCE_RETICLE_STATUS(实时) ─→ 推演 ─→ FSO_RETICLE_INFO(排程起点快照) ─→ Reticle 排程 ─→ FSO_RETICLE_TRANSPORT_CMD ─→ SDR
SOURCE_LOT + SOURCE_PRODUCT_FLOW(LAYER) + FSO_STACKING_LAYER_GROUP ─→ Stacking Bond ─→ FSO_LOT_VERTICAL_CONTROL
LOTHIST ─→ 上游 CycleTime/预计到站时间（前处理）
```
