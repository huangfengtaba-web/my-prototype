## 2. 各场景操作流程

### S1 日常排程 Loop 运行与发布（★★★）

> 目标：一个 Loop 内完成"数据就绪 → 求解 → 核对 → 下发"，全程 30 分钟内。

| 步骤 | 页面 | 操作 | 系统反馈 |
|---|---|---|---|
| 1 | model_zone · Schedule Model | 选定模型版本（如 Litho_Main V1.3），确认参数与 Auto Run 开关 | 参数清单回显；版本状态 Active |
| 2 | config_zone · 各页签 | 检查 Lot Control / Transport / Reticle Config 阈值无告警 | 红点提示未确认项 |
| 3 | result_litho · Scanner | 点击运行，查看甘特图（三态+Reticle 条） | 甘特渲染；QTMS 超水位红框标记 |
| 4 | result_litho · Barc Schedule | 核对 Is Release 与 Reason 列 | 放货窗口 ER/LR 逐行可查 |
| 5 | result_reticle · Transport | 确认搬送指令后点击下发 | SDR 指令状态：已下发/失败原因 |
| 6 | log_zone · Scheduling Log | 确认本次 Run 状态 Success | Model Name/Version/耗时记录 |

**关键决策点**：步骤 3 发现 QTMS 红框 → 转 S5 排查；步骤 4 有 FAIL 行 → 查 Reason 后决定跳过或改参数重跑。

### S2 急货插单（★★★，原型主故事线 LOT-A01+RT-0101）

> 目标：急货在 QTime 内插上机台，光罩 35 分钟准备链（IRIS 20 + 搬送 10 + 装载 5）兜得住。

| 步骤 | 页面 | 操作 | 系统反馈 |
|---|---|---|---|
| 1 | config_zone · Priority Config | 将 LOT-A01 标为 SHR/Super Bullet（Attribute Priority 1） | 优先级变更记录可追溯 |
| 2 | config_zone · Fix Lot | 固定 LOT-A01 → IMM03，锁定前序 | Fix Lot 数计数 +1 |
| 3 | result_litho · 中间结果 | 打开 🔍 溯源弹窗逐行核验六步过程产物 | 每行：一致性校验 PASS + 计算过程公式代入 + 源表字段 + 下游反查 |
| 4 | result_litho · Barc Schedule | 查看急货放货窗口（最早/最晚） | ER=03:30 / LR=09:30（§2.3 公式） |
| 5 | result_reticle · Chart/Transport | 确认 RT-0101 五态链：09:10 IRIS → 09:45 就绪 → 10:00 上机 | 甘特色块：Inspection→Transport→Process |
| 6 | result_litho · Scanner | 确认 10:00–10:34 加工 25 片无冲突 | 急货条高亮，相邻 Lot 自动让位 |

**关键决策点**：步骤 3 溯源出现 WARN/FAIL（如水位置换失败）→ 主管决定降级急货或人工干预储位；步骤 5 光罩就绪晚于放货最晚时间 → 触发放货顺延并通知 BARC 工段。

### S3 光罩状态查询与推演（★★☆）

| 步骤 | 页面 | 操作 | 系统反馈 |
|---|---|---|---|
| 1 | result_reticle · Schedule | 按五态色筛选查看全量光罩分布 | Process 蓝/Inspection 橙/StarLight 紫/Stocker 灰/Transport 绿 |
| 2 | 甘特条 hover | 查看单块光罩 11 字段（含 wafer_to_iris、StarLight 余量） | 悬浮卡显示明细 |
| 3 | result_reticle · Transport | 查当日搬送路径图与作业甘特 | IRIS/Load/Unload 按 Job Type 着色 |
| 4 | 储位水位 | 检查 Stocker 占用（物理 12 / 水位 10） | 满水位提示先搬出（RT-0204 案例） |

**关键决策点**：计片余量=0 或计时到期 → 系统自动排 IRIS（⑥推演触发三类）；水位满 → 搬出决策需要人确认。

### S4 模型调参与版本管理（★★☆）

| 步骤 | 页面 | 操作 | 系统反馈 |
|---|---|---|---|
| 1 | model_zone · Eqp Group | 调整机台分组/WPH | 分组表即时生效于下次 Run |
| 2 | model_zone · Data Parameter | 修改参数（chunk 大小/权重/时限） | 参数版本号 +1 |
| 3 | model_zone · Model Configuration | 另存为新版本（V1.3 → V1.4） | 新版本 Status=Draft |
| 4 | result_litho · 中间结果 | 切换运行批次对比两次 Run 指标 | MakeSpan/换罩次数/求解耗时并排 |
| 5 | model_zone · Schedule Model | 对比满意后置 Active | 旧版本归档 |

**关键决策点**：新版本指标劣化 → 回滚版本；参数改动涉及客户约束 → 需求方确认后才能 Active。

### S5 异常排查与日志回溯（★★☆）

| 步骤 | 页面 | 操作 | 系统反馈 |
|---|---|---|---|
| 1 | log_zone · Scheduling Log | 筛选 Status=Error/Abnormal 定位失败 Run | 错误类型：DATA/UNKNOWN/MODEL_ERROR |
| 2 | 错误行 · View Error | 携 query 跳转 Error Management | 自动过滤到对应错误 |
| 3 | Error Management · Detail | 查看错误信息与堆栈 | 弹窗展示 Error Info/Detail |
| 4 | result_litho · 中间结果 | 按 Run 批次回看六步产物，溯源定位是哪一步引入 | 溯源弹窗标出问题步骤与源字段 |
| 5 | 修复后重跑 | 更新配置/数据后重新 Run | 新批次 RUN-* 独立归档 |

**关键决策点**：DATA_ERROR → 找数据组；MODEL_ERROR → 找算法组；定位耗时是本场景核心 KPI（目标 <10 分钟）。

### S6 BARC 放货窗口管理（★☆☆，随 S1/S2 联动）

| 步骤 | 页面 | 操作 | 系统反馈 |
|---|---|---|---|
| 1 | result_litho · Barc Schedule | 按 Is Release 筛选待放货批 | 12 列含 ER/LR/Reason |
| 2 | 导出 CSV | 下发 BARC 工段执行 | 文件含 BOM，Excel 直接打开 |
| 3 | 异常行 | 查看 Reason（RunPath 断线/水位超标） | FAIL 行带错误信息 |
