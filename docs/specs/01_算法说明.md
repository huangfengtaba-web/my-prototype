## 1. 六步算法链总览

```
① 预处理 → ② Reticle 预组批(MILP) → ③ Lot 细排程(MILP, chunk≤50) → ④ 后处理 → ⑤ BARC 反推 → ⑥ 光罩状态推演
     └────────────────── 喂给 ③ ──────────────────┘        └─ 回写 ②⑥                    └─→ SDR/QTMS 联动
```

| 步骤 | 输入 | 核心 | 输出 |
|---|---|---|---|
| ① 预处理 | SOURCE_LOT / SOURCE_PRODUCT_FLOW / SOURCE_EQP_* / SOURCE_LOT_REMAIN_QTIME / LOTHIST | Lot 属性打标（Key Lot/Priority/Remain QTime/温层/连批）、机台可用性（UnFinishedProcessTime/PM）、Reticle 计片计时余量 | 前处理宽表 |
| ② Reticle 预组批 | 前处理 + SOURCE_RETICLE_STATUS | MILP：Lot Step 机台分配 + Reticle 分组（Train size 折中换罩次数） | Reticle Assignment + FSO_RETICLE_INFO 快照 |
| ③ Lot 细排程 | ②的分配 + ①属性 | MILP：chunk≤50 逐块排，QTime/Recipe Change/温层/Chuck 约束 | FSO_SCHEDULE_RESULT（14 字段出参） |
| ④ 后处理 | ③结果 | 同 Stage 间隔放货、水位校验、Fix Lot 冻结、SDR 两方案下发 | FSO_RETICLE_TRANSPORT_CMD |
| ⑤ BARC 反推 | ③结果 + Remain QTime | 由 Litho Start 反推 BARC 最早/最晚放货时间 | BARC_RELEASE_BATCH |
| ⑥ 光罩状态推演 | ③结果 + SOURCE_RETICLE_STATUS | 推演每块光罩在排程窗口的五态时序与就绪时间 | EARLIEST_AVAILABLE_TIME/LOCATION 回写 + 五态甘特 |

## 2. 关键模型

### 2.1 Reticle 预组批 MILP（设计书 §3.3.2.1）
- **决策变量**：x[l,e] ∈{0,1}（Lot l 是否分配机台 e）、y[l,r]（Lot-Reticle 绑定）、组批变量 b[l1,l2]（同 Reticle 连批）。
- **约束**：每 Lot 恰分配一个机台；Capability 匹配；Reticle 同时刻单机台占用；计片/计时余量（waferCountToIris/StarLight）不足即停止下货。
- **目标**：min 换罩次数 + MakeSpan 加权；保证当站 WIP 与 Follow In 不出 QTime Risk（RFP 2.1.4）。

### 2.2 Lot 细排程 MILP（设计书 §4.3.2.1）
- chunk≤50 逐块求解（time_limit/worker 参数见 FSO_CFG_PARAM）。
- 约束四类：**QTime**（Remain QTime 内上机）、**Recipe Change**（同 Recipe 优先连排）、**温层**（转温耗时 capability_temperature_change 计入）、**机台**（Running Mode/Diffusion 最大最小片数）。
- 目标：min MakeSpan + 优先级加权 tardiness（Attribute Priority 1~4 分档，见 §5 优先级）。

### 2.3 BARC 反推（设计书 §2）
- 最早放货 = Litho Start − BARC QTime − Process Time（例：上机 10:00、QTime 6h、PT 0.5h → 最早 3.5h 前放货）。
- 最晚放货 = Litho Start − Process Time（9.5h）。
- Batch 维度输出 BARC_RELEASE_BATCH；失败写 ERROR_MESSAGE（RunPath 断线/水位超标等 Reason 同源）。

### 2.4 光罩状态推演（PPT P5/P6 案例）
- 五态：Process→Inspection→StarLight→Stocker→Transport；起点 = EARLIEST_AVAILABLE_TIME/LOCATION（SOURCE_RETICLE_STATUS 推算）。
- 触发三类：计片（WAFER_COUNT_TO_IRIS=0）、计时（LAST_STARLIGHT_TIME 超 LifeTime）、切换（上机需求）。
- 急货案例：09:10 IRIS 20min → 09:30 搬送 10min → 装载 5min → **09:45 就绪** → 10:00 加工 25 片（35 = 20+10+5）。
- 储位水位：物理 12 / 水位 10 / 占用 10，满水位先搬出（RT-0204 案例）。

## 3. 优先级体系（设计书 §5）
| 档 | 判定 |
|---|---|
| Attribute Priority 1 | SHR/SSHR Bullet、Pilot、Remain QT<60min、Key Lot |
| Attribute Priority 2 | MES priority 1-*、Normal Bullet、Key Stage、插队 Quota、Move Target、Ship Lot |
| Attribute Priority 3 | MES priority 2-6-*、下游 LoadBalance Pull |
